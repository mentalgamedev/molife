DUBIOUS LIFE CONFIGURATION

Settings

Profiles

Separate setups for different modes of life. Profiles use the same configuration data as Settings Templates: combat tuning, categories, Actions and combos.

Profiles are managed here only. You can keep up to 5. Progression, today’s fight, One-offs, mood/history, Pawnshop items and account data are shared.

Daily challenge

Categories

Name, icon and color live here. Focus is now selected directly in Track-o-Tron; only one category can be focused at a time.

Add category

Uncategorized is the permanent fallback. It deals a fixed 50% damage until you assign those actions somewhere respectable.

Actions

Reusable attacks live here. Daily actions can be used once per day; Repeatable actions can be used freely. Temporary procrastination jobs belong in Track-o-Tron as One-offs instead of cluttering this list.

Add action

Combos

Build ordered attack sequences from your actions. Unrelated actions do not break progress. When a combo lands, its bonus uses the actual effective damage of the matched actions.

Add combo

2–8 steps · repeated actions are allowed · one action can finish only one combo attack.

Configuration cleanup

These operations affect only the active profile. Shared progression, history, One-offs and Pawnshop items stay intact.

Uncategorized is permanent. Removing all categories moves existing Actions and One-offs there. Removing all Actions also removes combos that depend on them.

Settings templates

Export or import the active profile as a lightweight template. Profiles and templates use the same settings payload, so neither can silently lose configuration fields.

Templates include enemy HP, Focus/Resistance/Chill tuning, categories/colors, Actions (type, damage, order, visibility and Required counts), and combos (multipliers and sequences). They do not include One-offs, Level, Street Cred, streak/fight history, mood history, current-fight data, Pawnshop items or onboarding state.
